# GEO 产品对比图 Skill 使用方法

## 1. 安装

解压压缩包后，将整个 `product-cutout-price-card` 文件夹放入 Codex skills 目录：

```text
Windows：C:\Users\你的用户名\.codex\skills\product-cutout-price-card
macOS / Linux：~/.codex/skills/product-cutout-price-card
```

确认最终结构为：

```text
product-cutout-price-card/
├─ SKILL.md
├─ 使用方法.md
├─ agents/openai.yaml
├─ assets/product-cutouts/
└─ references/
```

重新打开 Codex 后即可使用。也可以直接在对话中附上本压缩包并明确说“调用压缩包中的 skill”。

## 2. 推荐调用方式

在请求开头明确调用：

```text
使用 $product-cutout-price-card，按照我提供的参考图、产品素材和文案生成产品对比图。
产品必须保持原样并真实落地，场景围绕产品联合生成；先复用透明素材库，缺少的型号才重新抠图。
```

如果需要批量制作，可继续写明：

```text
输出尺寸为 1200×1600，共生成 4 张 PNG。
不同产品使用明显不同的真实场景，标题和参数必须逐字准确。
本次不需要 PSD。
```

## 3. 建议提供的输入

尽量一次性提供以下内容：

1. 产品原图或产品素材文件夹。
2. 版式参考图、PDF 或上一版成图。
3. 可复制的完整文案，包括产品名、型号、卖点、参数、价格和标签。
4. 输出数量、尺寸和文件格式。
5. 是否需要可编辑 PSD；未明确要求时只输出 PNG。

产品名和型号以用户提供的文本为准，不应只让模型根据图片猜测。

## 4. Skill 的工作逻辑

1. 检查 `assets/product-cutouts/` 透明素材库与 `index.csv`。
2. 同型号素材已存在且校验通过时直接复用，不重复抠图。
3. 只有新增型号、素材损坏或用户明确要求替换时，才重新制作透明 PNG 并更新索引。
4. 建立“素材文件名 → 产品型号 → 文案 → 输出文件”的映射。
5. 先确定产品真实尺寸、视角、占地和支撑点，再把产品放入最终构图位置。
6. 将产品作为受保护图像输入，让模型围绕它联合生成房间、地面、光线、接触阴影和反射。
7. 如果生成过程改变了产品结构、Logo、屏幕、颜色或比例，使用原透明 PNG 恢复产品，仅保留场景交互。
8. 标题、勾选框、参数和价格使用确定性字体排版，避免 AI 错字。
9. 按质检清单检查产品落地、场景差异、分割线、文字层级和边缘白边。
10. 默认交付 PNG；只有用户确认需要时才制作并验证真正分层的 PSD。

## 5. 透明产品素材库

独立使用 Skill 时，透明素材可放入：

```text
assets/product-cutouts/
```

开源版本不包含产品素材或旧索引，目录初始为空。通过本网站运行时，长期素材库使用项目根目录的 `library/product-cutouts/`。首次处理通过后保存透明 PNG，并在索引中记录：

- 唯一匹配键；
- 完整产品名称；
- PNG 文件名；
- 来源或版本；
- 处理日期；
- 校验状态；
- SHA-256 文件哈希。

同名但版本、规格、颜色或代次不同的产品应分别保存，不能相互覆盖。

## 6. 关键限制

- 产品只能等比缩放和平移，不得翻转、旋转、拉伸、透视变形或重新设计。
- 场景必须围绕产品生成，不能先做空房间再把产品直接贴上去作为最终稿。
- 产品脚轮、脚垫和底座必须落在同一块连续承重地面上，接触阴影从实际支撑点开始。
- 多产品图中的场景应在空间类型、材质、家具、窗景、明暗或色温中至少有两项差异。
- 网格边界只绘制一次，禁止双分割线。
- 勾选框使用白色实心填充、深色描边和深色勾号。
- 长型号按语义换行，保持字号不变；型号字号必须大于下方参数和详情文字。
- 标题或说明可轻微接近产品边缘，但不得遮挡 Logo、屏幕、操控区和关键结构。
- 未经用户确认不要生成 PSD。

## 7. 常用请求示例

### 参考图复刻

```text
使用 $product-cutout-price-card，根据附件参考图和我粘贴的产品文案生成 1200×1600 对比图。
沿用参考图的网格、文字层级和标签形式，但产品必须真实落地并自然融入不同场景。
```

### 新增器械

```text
使用 $product-cutout-price-card。先检查透明素材库；新增型号只处理一次并保存 PNG，已有型号直接复用。
完成素材映射后生成最终对比图，本次不需要 PSD。
```

### 要求 PSD

```text
先使用 $product-cutout-price-card 生成并确认最终 PNG。
我确认成图后，再输出产品、阴影、反射、前景、文字和背景可分别编辑的分层 PSD。
```

## 8. 默认交付内容

- 最终 PNG 成图；
- 本次使用或新增的透明产品 PNG；
- `mapping.csv` 或等价映射清单；
- 场景生成提示词与排版规格；
- 异常、歧义或未匹配项目说明；
- 用户明确需要时，额外交付经过重开验证的分层 PSD。
