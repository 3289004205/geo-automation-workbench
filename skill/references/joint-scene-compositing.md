# 产品与场景联合生成规范

本规范用于需要产品自然融入室内、户外或生活方式场景的成图。核心原则是：**先确定产品真实位置，再让场景围绕受保护的产品生成**，而不是先生成空场景再粘贴产品。

## 1. 联合输入画布

1. 从透明素材库读取已验收产品 PNG，只做等比缩放和平移，把产品放在最终构图位置。
2. 根据 [physical-placement.md](physical-placement.md) 标记实际支撑点、占地轮廓、相机视角和尺度依据；物理位置未通过时不要开始生成。
3. 制作产品保护蒙版：产品实心和半透明结构属于受保护区；阴影、透明区和产品外环境属于可生成区。
4. 把“已摆放产品 + 产品保护蒙版 + 场景描述”一起交给支持图像编辑、参考合成或局部生成的工具。产品必须是生成输入的一部分，不能只写型号名称让模型自行想象。

## 2. 生成目标

提示词要求场景围绕现有产品建立：

- 地面必须在产品所有支撑点下方连续生成，并与产品占地、镜头高度和消失方向一致。
- 家具和墙体根据产品实际体积退到后方或侧边，不得与机身穿插。
- 主光同时照亮房间与产品；地面从支撑点产生紧实接触阴影，再向背光方向形成更宽的投影。
- 根据材质生成克制的地面反射、环境色反弹和边缘光；不能给产品添加不存在的结构、接口、纹理或装饰。
- 允许真实的少量前景遮挡，但关键结构和品牌信息必须完整可见。

提示词必须重复以下产品不变量：保持产品轮廓、方向、长宽比、结构、颜色、材质、Logo、屏幕、按键和可见细节不变；只生成其周围环境及真实光影交互。

## 3. 产品保真回贴

生成工具即使收到保护指令，也可能改变产品。每次生成后都执行：

1. 将生成结果中的产品区域与同位置、同尺寸的原 PNG 对照。
2. 只要轮廓、Logo、屏幕、按键、结构或材质纹理发生变化，就用原 alpha 蒙版恢复原产品像素。
3. 恢复后只允许在产品内部叠加可撤销的低强度环境光层，例如整体曲线、色温、局部明暗和边缘光；这些层不得重绘内容，也不得覆盖 Logo、屏幕或细节。
4. 产品外部保留联合生成得到的接触阴影、投影、反射和环境遮挡，使场景交互不因回贴而丢失。

## 4. 修订次数与失败处理

- 首次联合生成应同时解决空间、地面和主光；必要时最多再做一次仅针对产品周围的局部交互修订。
- 若产品位置、透视或家具关系不合理，返回物理摆放阶段调整，而不是用更多阴影或模糊补救。
- 若工具无法把产品作为图像输入或无法保护产品区域，它不能承担最终融合；改用支持参考合成/编辑的工具。空房间生成后直接贴产品只可作为内部草图，不可交付。
- 为节省 token，不为同一产品批量生成多个空场景试贴。优先一次联合生成加一次明确的局部修订。

## 5. 可选 PSD

默认只交付联合融合的最终 PNG，同时保留原产品、保护蒙版和位置参数。只有用户确认需要 PSD 时：

- 产品层直接使用原透明 PNG。
- 对最终图中的产品占位区域做局部补全，生成不含产品的背景净版；不要从成图反向抠产品。
- 以最终图为参照重建接触阴影、宽投影、反射、受控补光和必要的前景遮挡层。
- 最终 PSD 的可见合成应与已确认 PNG 一致，并按 PSD 交付规范重新打开验证。
