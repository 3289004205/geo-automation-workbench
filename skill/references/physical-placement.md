# 产品场景物理摆放规范

本规范在任何场景联合生成前执行。目标是先确定产品在真实空间中的合理位置，再让场景围绕产品生成，确保“有地方可放、尺寸合理、支撑成立”。

## 1. 产品空间信息

对每件透明产品记录最少信息：

- 源图视角：正面、侧面或左/右前方三分之四视角，以及大致俯视程度。
- 实际支撑点：脚轮、脚垫、支架或底座与地面接触的位置；不能把透明图外接矩形的最底边当成地面。
- 占地轮廓：产品实际会占用的地面投影区域，包括跑带、支架和必要使用空间。
- 尺度依据：优先使用已知长宽高；没有参数时，用同类器械的合理范围作为临时假设，并在记录中标明。
- 不可遮挡区：Logo、屏幕、操控区、型号铭牌和关键结构。

## 2. 场景适配记录

每个产品卡片在排版前建立一条简短适配记录：

`产品 → 源图视角 → 连续可用地面区域 → 家具/墙体禁入区 → 尺度参照 → 主光方向 → 支撑点落位 → 通过/返工`

不要求制作复杂三维模型，但必须能从记录和摆放校验图判断产品为什么可以站在这里。

## 3. 联合场景生成准备

- 根据产品视角选择镜头，而不是让产品适应随机背景。三分之四俯视产品应搭配能看见足够地面的相近视角；低机位产品不能放进明显高俯视房间。
- 在联合输入画布中先确定产品占地和支撑点，场景生成时让连续、平整、可承重的地面围绕这些位置建立。大型器械区域内不得生成茶几、办公桌、椅子、沙发边缘、花盆、台阶或墙体。
- 家具应生成在产品后方或画面侧边，并保留符合真实使用的通行空间。提示词应明确“围绕当前受保护产品生成房间；产品占地区域为连续平地，无遮挡、无家具、无地毯高差、无人、无文字”。
- 地毯可以作为场景元素，但产品所有支撑点应完全位于地毯上或完全位于同一层地板上。除非已明确处理真实高差，否则不要横跨厚地毯边缘。
- 若联合结果没有足够空间、透视不符或家具无法避开，回到产品落位重新生成场景；不要裁切、缩小产品或用遮挡补救。

## 4. 合成落位

1. 在联合输入画布上标出产品占地、家具禁入区、地面消失方向和预计主光方向。
2. 按真实尺寸或保守尺度等比缩放并放置原透明产品；以门、沙发、桌椅、窗台等计划参照物约束场景生成尺度。
3. 将产品、保护蒙版和场景要求一起送入生成工具，让地面、家具、光线和阴影围绕现有产品建立。
4. 检查前后关系：产品应完整遮挡其后方场景；只有确实位于镜头与产品之间的前景物体才可少量遮挡产品。
5. 紧实接触阴影必须从每个主要支撑点向外扩散，支撑点与阴影之间在 `1200×1600` 成图中不得出现超过 `2 px` 的可见间隙；宽环境阴影沿地面和主光反方向展开。
6. 按联合生成规范恢复任何被改动的产品像素，再用低强度、可撤销的环境光层匹配色温、明暗和边缘光。

## 5. 一票否决条件

出现下列任一情况，摆放校验图直接判为不合格并返工：

- 任一主要支撑点悬空，或接触阴影没有从支撑点开始。
- 产品落在桌面、沙发、墙面、台阶立面等不合理表面，或与家具、墙体发生实体穿插。
- 产品源图视角与场景地面透视明显冲突，却通过旋转、透视变形或阴影强行掩盖。
- 产品尺度与门、沙发、桌椅或空间尺度明显不相称。
- 产品跨越明显高差、厚地毯边缘或不同地面，但机身没有相应倾斜和受力关系。
- 为容纳标题或详情把产品抬高、缩得不合理、移入家具区域或让支撑点离开地面。
- 背景物体错误地从产品中穿出，或本应在前景的物体没有形成正确遮挡。

摆放校验图通过后，才能进入文字排版、最终调色和交付检查。
