# 03/04 指定参考版式变体

仅当用户明确指定这两种参考版式时使用。本文件覆盖通用四宫格的文字顺序和对应模板坐标，不改变产品保真、场景融合、物理落地、文案真值及 PSD 授权规则。

## 03：三列双排跨缝标题

- 使用 `1200×1600` 满版画布，三列各 `400 px`、两排各 `800 px`。六个联合场景连续铺满各自单元格；只在 `x=400`、`x=800`、`y=800` 统一绘制一次 `4 px` 白色分割线。
- 产品型号不用黑色底板。型号采用黑色实心、荧光绿描边，所有卡片保持同一字号；长型号按语义分两行，不缩字。上排标题区约为全局 `y=95–205`，下排约为 `y=930–1010`，水平居中。
- 类别词采用白色实心、深灰描边，字号略大于型号；上排约为 `y=570–650`，下排约为 `y=1380–1465`，不得遮挡产品关键结构。
- 跨缝主标题为两行，白色实心、橙色内描边、黑色外描边。第一行位于约 `y=655–800`，第二行位于约 `y=790–930`；标题绘制在场景和分割线之后，直接覆盖横向接缝，不插入空白带。
- 文字层级建议为 `跨缝主标题 : 类别词 : 产品型号 = 2.3 : 1.25 : 1`。在 `1200×1600` 画布上可从主标题 `112–118 px`、类别词 `62–66 px`、型号 `48–54 px` 起调；只调整位置或语义换行，不为长型号单独缩小字号。

## 04：四宫格卖点上移

- 使用 `1200×1600` 满版画布，四格各 `600×800 px`；只在 `x=600`、`y=800` 统一绘制一次 `4 px` 白色分割线。
- 每格阅读顺序改为“产品名 → 绿色核心卖点 → 场景中的产品 → 底部详细说明”。此顺序仅覆盖通用四宫格的默认顺序。
- 产品名使用白色实心、橙色内描边、黑色外描边，位于每格顶部；单行标题约 `70–72 px`，长标题按语义分两行并使用约 `64 px` 的固定字号。上排单行标题局部顶点约为 `y=38`，长标题与下排单行标题约为 `y=20`。
- 绿色卖点框紧接产品名：上排位于单元格局部 `y=182–247`，下排位于局部 `y=122–187`，字号约 `36–40 px`。卖点框必须在产品主体上方，不能下沉到产品底部。
- 所有绿色卖点底卡必须位于橘黑产品型号图层下方。出现位置交叠时，先绘制绿色底卡，再绘制完整的黑色外描边、橙色内描边和白色字面，最后绘制绿色卡内的黑色卖点文字；绿色矩形不得盖住或截断型号描边。
- 三行详情固定在单元格底部：上排局部顶点约为 `y=639`，下排约为 `y=623`。使用 `30–34 px` 白字和独立深灰底条，行高约 `45–49 px`；按参考图在每格左侧保留约 `24–30 px` 固定内边距，三行共用同一左起点，短行保留自然右侧留白。本变体的固定左缩进优先于通用卡片的整块居中规则。
- 产品型号必须明显大于卖点和正文；产品、卖点框与正文不能遮挡屏幕、Logo、操控区和关键结构。文案与参考图冲突时，优先微调文字位置，不改变产品的方向、比例、尺寸关系或物理落点。

## 绘制顺序与验收

1. 读取已经通过物理落地和场景融合检查的无字联合场景；本变体不重新生成产品，也不拆分产品与背景。
2. 先铺满场景，再绘制唯一一组分割线。04 按“绿色卖点底卡 → 橘黑产品型号 → 卖点文字 → 详情文字”绘制；03 的跨缝主标题必须最后绘制。
3. 白色字面、橙色内描边和黑色外描边必须使用同一字体、字号、换行、字距、绘制原点和基线。只允许按描边宽度向外扩张；不得让各层按自身描边边界分别居中。多行标题必须先拆成固定行框，再逐行用同一原点绘制全部描边层；不得对不同描边宽度分别调用自动多行排版，因为描边宽度会改变自动行距并造成第二行黑边下坠。
4. 原尺寸检查：无重复分割线、无空白过渡带、长型号未缩字、04 的绿色卖点位于产品上方、详情位于底部，多重描边同心贴合，且全部文案逐字正确。
